# 物业楼栋外墙渗水季节复查系统

物业完成外墙渗水维修后，需在**有效降雨之后**回到原位置复查，住户才能确认渗水真正解决。
本系统覆盖「报修 → 施工 → 雨后复查」全流程，并支持同点位多户关联、复发报修与住户异议处理。

## 技术栈

- **后端**：Java 21 + Quarkus（REST、Hibernate ORM Panache）+ SQLite（文件库 `backend/data/seepage.db`）
- **前端**：Svelte + Vite（构建产物由 Quarkus 直接托管）
- **天气**：本地模拟（录入降雨事件、推进模拟时钟），有效降雨阈值默认 ≥10mm
- **照片**：本地磁盘存储（`backend/data/photos`），按 报修/施工/复查 阶段归档

## 启动

```bash
./start.sh          # 首次运行会下载 Maven/npm 依赖，需几分钟
# 打开 http://localhost:8080
```

`./start.sh --rebuild` 强制重新构建后端。每次启动都会重建数据库并写入演示种子数据（模拟当前日期 2026-10-06）。

## 业务规则

- 工单状态机：`待受理 → 维修中 → 待复查 → 复查通过`；复查未通过回到 `维修中`；住户异议进入 `异议处理中`。
- **雨后复查条件**：完工日之后（不含当天）须发生一场有效降雨（雨量 ≥ 10mm，且不晚于模拟当前日期）。
  未满足时工单保持「待复查」，提交复查会被后端拒绝 —— 完工当天不能直接标记验证通过。
- **同点位关联**：同一渗水点被多户报修时可关联到同一「渗水点位」，各住户工单与照片独立保留。
- **复发报修**：修复验证后再次漏水，登记为原工单的复发，详情页可回溯此前处理过程。
- **异议**：住户不认可复查结论可提出异议，物业回复并选择处理方式（维持结论 / 重新维修 / 再次复查）。

## 演示流程（种子数据已预置）

| 工单 | 场景 |
|---|---|
| #1 3栋东立面501 | 全流程已复查通过 |
| #2 3栋东立面502 | 与 #1 **同点位关联**；昨日完工、之后无有效雨 → **待复查（未达条件）** |
| #3 5栋北立面1201 | 维修中 |
| #4 3栋东立面501 | #1 的**复发报修**（待受理） |
| #5 2栋南立面303 | 复查通过后住户**异议**，物业回复安排二次复查（仍待有效雨） |

1. **未达到复查条件**：打开工单 #2 → 复查资格卡片显示「完工后暂无有效降雨」，提交按钮禁用；直接调 API 也会被拒。
2. **天气模拟补雨**：进入「天气模拟」→ 录入一场 2026-10-07、15mm 的降雨 → 回到工单 #2，变为「已满足雨后复查条件」→ 提交复查通过。
3. **同点位关联**：进入「渗水点位」查看 3栋东立面 点位下三户工单；或新建报修时选择「同点位关联」。
4. **复发报修**：打开工单 #1 → 「登记复发」→ 新工单详情页可看到原工单链接与完整历史。
5. **异议**：打开任一「复查通过」工单 → 「住户提出异议」→ 物业在工单页回复并选择处理方式。

## 主要接口

```
GET/POST /api/tickets                    工单列表 / 新建报修
GET      /api/tickets/{id}               详情（报修/施工/复查照片与结论、点位、复发链、异议）
POST     /api/tickets/{id}/start-repair  受理派工
POST     /api/tickets/{id}/construction  登记施工并完工 → 待复查
GET      /api/tickets/{id}/recheck-eligibility  复查资格（完工后有效降雨）
POST     /api/tickets/{id}/recheck       提交复查（未达雨后条件返回 400）
POST     /api/tickets/{id}/photos?phase=REPORT|CONSTRUCTION|RECHECK  照片上传
POST     /api/tickets/{id}/link-point/{pointId}  同点位关联
POST     /api/tickets/{id}/recurrence    复发报修
POST     /api/tickets/{id}/disputes      住户异议
POST     /api/tickets/{id}/disputes/{did}/reply  物业回复异议
GET      /api/points                     点位列表（含各户工单）
GET/POST /api/weather[/events]           天气模拟 / 录入降雨
GET      /api/weather/reminders          待复查天气提醒
GET      /files/{name}                   照片文件
```
